# DyIsd

A dynamic island for Windows 11: a pill at the top of the screen that shows what's playing,
volume/brightness changes, charging, notifications, a focus timer, a distraction nudge,
clipboard, deadlines and downloads. Hidden when idle. Can sit left, center or right.

## Status
- [x] Interactive design prototype: `prototype/island.html` (open in any browser)
- [ ] Windows app (C# + .NET 8 + WPF)
